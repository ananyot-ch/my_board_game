# my_board_game

Online multiplayer Thai Monopoly + Werewolf — NestJS backend + React frontend, real-time via Socket.io.

## Quick start (local Docker)

```bash
docker compose up
```

- Frontend: http://localhost:5173
- Backend:  http://localhost:3000/api/health
